# Orzmic Resource
This script is used for extracting files from the orzmic apk.
The script was improved by [OrzmicNotes](https://github.com/7aGiven/OrzmicNotes).
Acknowledgements: [7aGiven](https://github.com/7aGiven)
Resources include:
Character illustrations, character introductions, track information, chart data, track art, and track audio.

# Usage Example
<pre><code>$ python3 main.py orzmic.apk</code></pre>
※ The apk needs to be in the same directory as the script.
